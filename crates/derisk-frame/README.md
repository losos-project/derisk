# derisk-frame

The frame every derisk app is drawn in, taken from Settings: a sidebar of
grouped pages (tabs across the top on a phone), a page's title and the line
under it, cards holding what the page shows, and a bar along the bottom for
what acts on it. Every colour, radius and font size comes from the theme's
component tokens, so a theme or a change here restyles every app at once.

Part of [derisk](https://github.com/losos-project/derisk), where it is built as
a member of the derisk Cargo workspace; see the README there.

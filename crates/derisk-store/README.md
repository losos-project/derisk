# derisk-store

derisk Store app: Flathub's apps sorted into categories from their AppStream
data, with their release notes on the front page, installed, updated and
removed through flatpak on this computer or in the machine that runs Flatpak.

Part of [derisk](https://github.com/losos-project/derisk), where it is built as
a member of the derisk Cargo workspace; see the README there.
